# موقع المنصّة الموحّدة للتدبير المدرسي

موقع تعريفي ثابت (HTML/CSS/JS فقط، بلا أي إطار عمل أو خطوة بناء) لعرض المنصّة
وإتاحتها للتحميل، مع دليل الاستعمال والفيديوهات التوضيحية.

## الصفحات

| الملف | المحتوى |
|---|---|
| `index.html` | الصفحة الرئيسية: التعريف، المحاور الستة، لمحة من التطبيقات، مكتبة الأدلة |
| `apps.html` | كتالوج التطبيقات التسعة عشر مع تصفية حسب المحور وبحث ودُرج تفاصيل |
| `videos.html` | مشغّل الفيديوهات السبعة مع قائمة تشغيل واستئناف من نقطة التوقّف |
| `guide.html` | دليل الاستعمال الكامل + الأسئلة الشائعة + مكتبة الأدلة (20 ملف PDF) |
| `download.html` | صفحة التحميل ومتطلّبات التشغيل وما بعد التحميل |

## البنية

```
موقع/
├── index.html · apps.html · videos.html · guide.html · download.html
├── assets/
│   ├── css/site.css      نظام التصميم كاملًا (سمة فاتحة وداكنة)
│   ├── js/data.js        سجلّ المحاور والتطبيقات والفيديوهات والأدلة ← عدِّل هنا
│   └── js/site.js        منطق الواجهة المشترك
├── downloads/
│   ├── unified-platform.html      ملف المنصّة المعروض للتحميل
│   └── guides/*.pdf               20 دليلًا (15 للتطبيقات + 5 عامة)
└── videos/*.mp4                   7 فيديوهات (≈354 مب)
```

## التحديث

كلّ المحتوى المتغيّر مُجمَّع في **`assets/js/data.js`**:

- **تحديث المنصّة**: استبدل `downloads/unified-platform.html` بالنسخة الجديدة
  (الاسم نفسه)، وحدِّث الحجم المذكور في `index.html` و`download.html`.
- **إضافة تطبيق**: أضف عنصرًا إلى `APPS` + لقطة شاشة في `assets/img/`.
- **إضافة فيديو**: ضع الملف في `videos/` وأضف عنصرًا إلى `VIDEOS`
  (`len` بالثواني، و`dur` نصًّا للعرض).
- **إضافة دليل**: ضع الـPDF في `downloads/guides/` وأشِر إليه من حقل `guide`
  في التطبيق، أو أضفه إلى `LIBRARY` إن كان دليلًا عامًّا.

## المعاينة محليًّا

```bash
python -m http.server 8899
```

ثم افتح <http://localhost:8899>. (يعمل الموقع أيضًا بفتح `index.html` مباشرةً
من القرص، لأنه لا يعتمد على `fetch` في تحميل بياناته.)

## النشر

### 1) جهّز مجلّد الرفع

```bash
python build-deploy.py
```

ينشئ مجلّد `dist/` الجاهز للرفع (52 ملفًا، 29 مب): نسخة من الموقع بلا
`videos/` ولا `.claude/` ولا هذا الملف ولا السكربت نفسه، مع `robots.txt`.
وينبّهك إن بقي فيديو بلا رابط يوتيوب. بعد معرفة عنوان موقعك أعد تشغيله
مع النطاق ليُنشئ خريطة الموقع أيضًا:

```bash
python build-deploy.py --domain almanassa.pages.dev
```

**أعد تشغيل السكربت بعد كل تعديل على الموقع**، فـ`dist/` نسخة مجمّدة تُبنى من جديد
في كل مرّة (يُحذف القديم كاملًا). لا تعدّل داخل `dist/` مباشرةً.

### الطريقة المعتمدة: GitHub ← Vercel

جذر المستودع **هو** الموقع، فلا خطوة بناء ولا إعدادات: كل `git push` ينشر تلقائيًّا
خلال نحو نصف دقيقة.

```bash
git add -A
git commit -m "تحديث الموقع"
git push
```

| الملف | دوره |
|---|---|
| `vercel.json` | ترويسات الأمان والتخزين المؤقّت (فيرسل لا يقرأ `_headers`) |
| `.gitignore` | يستبعد `videos/` — `platform-full.mp4` يبلغ 227 مب وحدّ GitHub 100 مب، فبدونه يُرفض الدفع كاملًا |
| `.vercelignore` | يستبعد README والسكربت من النشر (يبقيان في المستودع) |
| `.gitattributes` | يوحّد نهايات الأسطر ويحمي الملفات الثنائية |

إعدادات مشروع فيرسل: Framework Preset = **Other**، Root Directory = **./**،
بلا Build Command وبلا Output Directory.

> **حزمة التدفّق:** خطة فيرسل المجّانية 100 جب/شهر. أكبر مستهلك هو ملف المنصّة
> (6.4 مب لكل تحميل). إن ضعت الحزمة، ارفع الملف إلى **GitHub Releases**
> (تدفّقه غير محدود) وبدّل رابط زرّ التحميل في الصفحات الخمس إلى رابط الإصدار،
> فينخفض استهلاك فيرسل إلى مجرّد تصفّح الصفحات.

### طريقة بديلة: استضافة بالسحب والإفلات

**الموصى به — Cloudflare Pages** (مجّاني، وتدفّق بلا حدّ، مهمّ إن انتشر الرابط):
أنشئ حسابًا ← Workers & Pages ← Create ← Pages ← **Upload assets** ← اسحب مجلّد
`dist` ← Deploy. تحصل على عنوان `اسمك.pages.dev` بشهادة SSL مجّانية.
التحديث لاحقًا: نفس الصفحة ← Create new deployment ← اسحب `dist` من جديد.

**الأبسط للتجربة — Netlify Drop**: <https://app.netlify.com/drop>، تسحب `dist`
فتحصل على رابط حيّ فورًا. سقفه 100 جب/شهر (≈12,000 تحميل للمنصّة).

يعمل كذلك على GitHub Pages أو أي استضافة عبر FTP — ارفع محتوى `dist/` إلى
المجلّد الجذر. لا يحتاج خادمًا ولا قاعدة بيانات ولا PHP.

### ملفات النشر المرافقة

| الملف | الدور |
|---|---|
| `404.html` | صفحة «غير موجودة» بتصميم الموقع — تعرضها Cloudflare و Netlify تلقائيًّا |
| `_headers` | ترويسات التخزين المؤقّت والأمان (تقرأها Cloudflare و Netlify، وتتجاهلها GitHub Pages) |
| `robots.txt` · `sitemap.xml` | يولّدهما السكربت لمحرّكات البحث |

> `404.html` يحوي `<base href="/">` ليعمل على أي مسار خاطئ. إن نشرت الموقع
> داخل مجلّد فرعي (مثل GitHub Pages للمشاريع) فاحذف ذلك السطر.

## الفيديوهات

سجلّ الفيديوهات في `VIDEOS` داخل `assets/js/data.js`. **17 فيديو**، منها
واحد مميَّز (`featured: true`) هو الجولة الكاملة، والبقية جولة لكلّ تطبيق.

| الحقل | الدور |
|---|---|
| `id` | معرّف فريد — يظهر في الرابط `videos.html?v=<id>`، وهو أيضًا اسم ملف mp4 الاحتياطي |
| `yt` | رابط يوتيوب بأي صيغة (`youtu.be/…` أو `watch?v=…` أو المعرّف وحده). **فارغ ⇐ يُشغَّل من `videos/<id>.mp4`** |
| `app` | يجب أن يطابق `id` في `APPS` — وإلا لن يُربط الفيديو بتطبيقه |
| `ax` | يجب أن يطابق `id` في `AXES` — وإلا أخذ الفيديو **لون المحور الأول واسمه** بصمت |
| `img` | اسم اللقطة في `assets/img/` (بلا امتداد) |
| `dur` · `len` | المدّة نصًّا، والمدّة بالثواني (تُستعمل في الاستئناف من نقطة التوقّف) |

**اربط التطبيق بفيديوه في الاتجاهين:** أضف `video:'<video-id>'` إلى مدخل
التطبيق في `APPS` أيضًا، وإلا لن يظهر زرّ «شاهد الفيديو التوضيحي» في دُرجه.

### الفحص قبل النشر

`build-deploy.py` **يقيّم `data.js` فعليًّا عبر node** (لا بتعبير نمطي) ويرفض
البناء عند أي من هذه:

- معرّف فيديو مكرّر، أو رابط يوتيوب مستعمل في مدخلين
- `app` أو `ax` لا يطابق شيئًا
- `APPS.video` يشير إلى فيديو غير موجود
- دليل PDF أو لقطة مشار إليها وغير موجودة على القرص
- فيديو بلا رابط يوتيوب (تنبيه — لأن `videos/` غير مرفوع)

هذه الفحوص أهمّ ممّا تبدو: مرجع خاطئ في `ax` **لا يُعطِّل شيئًا**، بل يعرض
الفيديو بلون محور آخر واسمه — خطأ صامت لا يُكتشف بالتصفّح العادي.

### كيف يشتغل المشغّل

- إطار يوتيوب **لا يُحمَّل إلا بعد نقر الزائر على زرّ التشغيل** (نمط الواجهة
  الوهمية): الصفحة تبقى خفيفة، ولا يُحمَّل أي مكوّن خارجي قبل المشاهدة.
- الصور المصغّرة مأخوذة من لقطات التطبيقات في `assets/img/` لا من يوتيوب،
  فهي أنظف وأسرع.
- خاصية **الاستئناف من نقطة التوقّف** تظلّ تعمل مع يوتيوب عبر واجهته البرمجية،
  وإن تعذّر تحميلها يظلّ الفيديو يعمل ويفقد تتبُّع الموضع فقط.
- استُعمل نطاق `youtube-nocookie.com` لتقليل التتبُّع.

### بديل: ضغط الفيديوهات بدل رفعها

```bash
ffmpeg -i videos/platform-full.mp4 -vcodec libx264 -crf 30 -preset slow -acodec aac -b:a 96k videos/platform-full-small.mp4
```

## توزيع المنصّة — بالطلب لا بالتحميل

ملف المنصّة `downloads/unified-platform.html` **لا يُنشر على الموقع**: مستبعد من
`.gitignore` و`.vercelignore` ومن `build-deploy.py`. كل أزرار «اطلب نسخة من المنصّة»
تفتح رسالة بريد معبَّأة مسبقًا.

**نصّ الرسالة وعنوان المراسَلة في مكان واحد:** ثابتا `REQUEST_MAIL` و`REQUEST_URL`
في `assets/js/data.js`. الأزرار في HTML تحمل `data-request` مع `mailto` بسيط،
ويرقّيها `site.js` إلى الرابط المعبَّأ — فتعمل حتى لو عُطِّل جافاسكريبت.

> **مهمّ عند الإرسال:** جيميل وأغلب خدمات البريد **تحجب مرفقات `.html`**.
> اضغط الملف في `.zip` قبل إرساله. صفحة الطلب والأسئلة الشائعة تشرحان
> للمستقبِل أنّ النسخة تصل مضغوطة وكيف يفكّها.

### الاستمارة

كل أزرار «اطلب نسخة» تقود إلى `download.html#request`، حيث **استمارة جوجل مضمَّنة**
في إطار. النصّ والحقول والردود كلّها تُدار من جوجل، والنتائج تتراكم في جدول Sheets
— وهو ما يخدم هدف إحصاء المؤسسات.

الروابط في `assets/js/data.js` (ثابت واحد يكفي لتبديل الاستمارة):

| الثابت | الدور |
|---|---|
| `GFORM_ID` | معرّف الاستمارة — غيّره وحده لتبديلها |
| `GFORM_EMBED` | رابط التضمين (`?embedded=true`) داخل الإطار |
| `GFORM_OPEN` | رابط الفتح في نافذة مستقلّة |
| `GFORM_SHORT` | الرابط القصير `forms.gle` للمشاركة على واتساب |

مصدر الإطار يُحقن من `site.js` لا من HTML، فلا تُحمَّل جوجل إلا في صفحة الطلب.

**ارتفاع الإطار مقيس لا مقدَّر:** محتوى الاستمارة 1622px عند عرض 1280، و1856px
عند 375. القيم في CSS هي 1720px و1960px مع هامش أمان — إطارٌ أقصر من محتواه
يُنتج تمريرًا داخل تمرير، وهو أسوأ ما يصيب الاستمارات المضمَّنة على الهاتف.
**إن أضفت أسئلة إلى الاستمارة فارفع الارتفاعين** في `.gform-card iframe`.

فوق الإطار شريط فيه رابط «افتحها في نافذة مستقلّة»، وتحته سطر احتياطي بالبريد
لمن تعذّر عليه ظهور الإطار (حاجب إعلانات مثلًا).

**للعودة إلى التحميل المباشر لاحقًا:****للعودة إلى التحميل المباشر لاحقًا:** احذف السطر من الملفات الثلاثة أعلاه،
وأعِد أزرار `data-request` إلى
`href="downloads/unified-platform.html" download="…"`.

## الخصوصية

الموقع لا يجمع أي معطيات ولا يستعمل أدوات تتبُّع. المكوّنات الخارجية الوحيدة:
خطّ Cairo من Google Fonts، ومشغّل يوتيوب الذي لا يُحمَّل إلا بنقرة الزائر.
التخزين المحلي مستعمل فقط لتذكّر السمة وموضع التوقّف في الفيديو.
